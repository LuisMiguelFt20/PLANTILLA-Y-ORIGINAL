Proyectos desarrollados

Algunos trabajos realizados durante mi formación académica.

Sistema Web de Gestión para Clínica Dental

Gestión de pacientes, citas y pagos

Sistema web desarrollado para mejorar la gestión administrativa de una clínica dental. Permite organizar información relacionada con pacientes, programación de citas y control de pagos, facilitando el acceso y administración de los datos.

Tecnologías: HTML5, CSS, JavaScript y Base de Datos.

Aplicación Móvil de Recordatorio de Medicamentos

Organización de horarios de medicamentos

Aplicación móvil desarrollada para ayudar al usuario a organizar y recordar los horarios establecidos para tomar sus medicamentos, ofreciendo una herramienta sencilla y práctica para gestionar sus recordatorios.

Tecnologías: Flutter y Dart.

Sistema Web Integrado con Base de Datos

Gestión de información mediante una plataforma web

Sistema desarrollado mediante la integración de una interfaz web con una base de datos. El proyecto permite registrar, almacenar, consultar y administrar información desde una página web de manera organizada.

Tecnologías: HTML5, CSS, JavaScript y SQL.
