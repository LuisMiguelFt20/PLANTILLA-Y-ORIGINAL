Sistema Web de Gestión para Clínica Dental

Proyecto académico orientado a mejorar la gestión administrativa de una clínica dental.

Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema web orientado a mejorar la organización y administración de una clínica dental.

El sistema busca centralizar información importante relacionada con los pacientes, las citas programadas y el control de pagos, permitiendo que los datos sean administrados de una manera más ordenada y accesible.

Problema identificado

En una clínica dental, realizar el registro de pacientes, citas y pagos de manera manual puede generar dificultades en la organización de la información.

Esto puede ocasionar pérdida de datos, duplicidad de información, demoras en la atención y dificultades para consultar los registros cuando son necesarios.

Objetivo del proyecto

Desarrollar un sistema web que permita centralizar y organizar la información administrativa de una clínica dental, facilitando la gestión de pacientes, citas y pagos.

Principales funcionalidades

  • Registro y administración de pacientes.
  • Programación y organización de citas.
  • Registro y control de pagos.
  • Consulta de información almacenada.
  • Organización centralizada de los datos.

Tecnologías utilizadas

HTML5

Estructura y organización de la interfaz web.

CSS

Diseño y presentación visual del sistema.

JavaScript

Interactividad dentro de la aplicación.

Base de Datos

Almacenamiento y organización de la información.

Mi participación

Durante el desarrollo del proyecto participé en la elaboración y organización del modelo conceptual del sistema, considerando como elementos principales al paciente, la cita y el pago.

También participé en la definición de las relaciones entre estos elementos y en la organización general de la información necesaria para el funcionamiento del sistema.

Aprendizajes obtenidos

Este proyecto me permitió fortalecer mis conocimientos relacionados con el análisis de sistemas, organización de información, bases de datos y desarrollo de soluciones web orientadas a resolver problemas reales.
