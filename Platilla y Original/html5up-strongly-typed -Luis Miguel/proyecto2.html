Aplicación Móvil de Recordatorio de Medicamentos

Aplicación desarrollada con Flutter para organizar recordatorios de medicamentos.

Descripción del proyecto

Este proyecto consiste en una aplicación móvil desarrollada para ayudar al usuario a organizar y recordar los horarios establecidos para tomar sus medicamentos.

La aplicación busca ofrecer una herramienta sencilla y práctica que permita registrar medicamentos y consultar los recordatorios de manera organizada desde un dispositivo móvil.

Problema identificado

Las personas pueden tener dificultades para recordar los horarios establecidos para tomar sus medicamentos, especialmente cuando deben seguir diferentes horarios durante el día.

Por ello, una aplicación móvil de recordatorios puede facilitar la organización de esta información y permitir que el usuario tenga sus horarios registrados en un solo lugar.

Objetivo del proyecto

Desarrollar una aplicación móvil que permita registrar y organizar recordatorios relacionados con los horarios de medicamentos, utilizando una interfaz sencilla y fácil de utilizar.

Principales funcionalidades

  • Registro de medicamentos.
  • Configuración de horarios.
  • Visualización de recordatorios.
  • Organización de medicamentos registrados.
  • Interfaz adaptada para dispositivos móviles.

Tecnologías utilizadas

Flutter

Framework utilizado para desarrollar la interfaz y estructura de la aplicación.

Dart

Lenguaje utilizado para implementar la lógica de la aplicación.

Android

Plataforma utilizada para probar y ejecutar la aplicación en dispositivos móviles.

Desarrollo de la aplicación

Para el desarrollo del proyecto se trabajó con Flutter y Dart, utilizando diferentes widgets para construir la interfaz de usuario y organizar los elementos principales de la aplicación.

La aplicación fue diseñada buscando que la navegación y el registro de información sean simples y comprensibles para el usuario.

Mi participación

Participé en el desarrollo de la aplicación, la creación de sus interfaces y la implementación de las funcionalidades necesarias para organizar los recordatorios de medicamentos.

También trabajé con Flutter y Dart para estructurar las diferentes pantallas y organizar la información presentada al usuario.

Aprendizajes obtenidos

Este proyecto me permitió fortalecer mis conocimientos en desarrollo móvil con Flutter, programación con Dart, diseño de interfaces y organización de información dentro de una aplicación móvil.
