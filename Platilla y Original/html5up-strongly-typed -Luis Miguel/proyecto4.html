Portafolio Web Personal

Sitio web desarrollado para presentar mis proyectos, habilidades y perfil académico.

Descripción del proyecto

Este proyecto consiste en el desarrollo de un portafolio web personal creado para presentar información sobre mi formación académica, proyectos desarrollados, habilidades tecnológicas y medios de contacto.

El sitio está organizado en diferentes secciones para facilitar la navegación y permitir que la información más importante pueda consultarse de una manera clara y ordenada.

Problema identificado

Los proyectos y conocimientos adquiridos durante la formación académica pueden encontrarse distribuidos en diferentes archivos y plataformas, lo que dificulta presentarlos de manera organizada.

Por este motivo, se desarrolló un portafolio web que permite reunir en un solo sitio información personal, proyectos, habilidades y medios de contacto.

Objetivo del proyecto

Desarrollar un sitio web personal moderno, organizado y responsive que permita presentar mi perfil académico, habilidades y proyectos realizados durante mi formación en Ingeniería de Sistemas.

Principales funcionalidades

  • Presentación de información personal.
  • Visualización de proyectos desarrollados.
  • Sección de habilidades y tecnologías.
  • Información y formulario de contacto.
  • Navegación entre las diferentes secciones.
  • Diseño adaptable a computadora, tablet y dispositivos móviles.
  • Menú hamburguesa para dispositivos móviles.
  • Desplazamiento suave entre secciones.
  • Botón flotante para regresar al inicio.

Tecnologías utilizadas

HTML5

Utilizado para estructurar y organizar el contenido del portafolio.

CSS3

Utilizado para personalizar el diseño visual y adaptar el sitio a diferentes pantallas.

JavaScript

Utilizado para agregar interactividad y mejorar la navegación del sitio.

GitHub

Utilizado para almacenar y publicar el código del proyecto.

Desarrollo del portafolio

Para desarrollar este proyecto se utilizó como base la plantilla Strongly Typed de HTML5 UP, adaptándola para convertirla en un portafolio web personal.

Se modificó la estructura del contenido, los colores, las secciones, los proyectos, la navegación y diferentes elementos visuales para personalizar el sitio.

También se realizaron ajustes responsive para que el contenido pueda visualizarse correctamente en diferentes tamaños de pantalla.

Mi participación

Realicé la personalización y organización del portafolio, modificando la estructura HTML, los estilos CSS y diferentes elementos de navegación e interactividad.

También organicé la información de mis proyectos, la sección de habilidades, la presentación personal y los medios de contacto.

Interactividad implementada

Se utilizaron funcionalidades JavaScript para mejorar la experiencia de navegación dentro del portafolio.

  • Desplazamiento suave entre secciones.
  • Botón flotante para volver al inicio.
  • Menú responsive para dispositivos móviles.

Aprendizajes obtenidos

Este proyecto me permitió fortalecer mis conocimientos en HTML5, CSS3 y JavaScript, así como comprender mejor la organización y estructura de un sitio web.

También me permitió aprender a personalizar una plantilla existente, trabajar con diseño responsive y organizar diferentes proyectos dentro de un portafolio personal.
